KROK 5: MAPOVÁNÍ NA SCL (1:1)
================================================================================

PŘÍKLAD: Kompletní SCL ekvivalent kroku 17

TYPE
    E_STEP_Flow2 : (
        STEP_Flow2_F2_Initial    := 1,
        STEP_Flow2_S4            := 4,
        STEP_Flow2_S5            := 5,
        ...
        STEP_Flow2_S17           := 17,  // ServoPosCount
        ...
    ) INT := 1;
END_TYPE

FUNCTION_BLOCK "FB_ST10_Flow2_A1TableUnloading"
VAR
    State : INT := STEP_Flow2_F2_Initial;
END_VAR

BEGIN
    CASE #State OF
        // =========================================================
        // STEP 17: ServoPosCount
        // SOURCE: XML Step Number="17", Actions with Event="S1"
        // =========================================================
        STEP_Flow2_S17:
            // Action Qualifier=N (Event=S1 - executed once on entry)
            // SOURCE: XML Action Token="ServoV90_DeviceCtl.V90Servo[1].nPositionListNo := ... + 1"
            "ServoV90_DeviceCtl".V90Servo[1].nPositionListNo :=
                "ServoV90_DeviceCtl".V90Servo[1].nPositionListNo + 1;

            // Action Qualifier=N (Event=S1)
            // SOURCE: XML Action Token="AutoProcessControl.A_Table_1Loading.ServoRunCount := ... + 1"
            "AutoProcessControl".A_Table_1Loading.ServoRunCount :=
                "AutoProcessControl".A_Table_1Loading.ServoRunCount + 1;

            // Transition 118 evaluates in next cycle
            // IF transition_condition THEN #State := STEP_Flow2_S18; END_IF;

    END_CASE;
END_FUNCTION_BLOCK;

KROK 6: TRACEABILITA (Zpětná dohledatelnost)

PRINCIP:
  Každý SCL blok obsahuje komentář:
  // SOURCE: XML Tag=<Step|Transition|Action>, Number="XXX", Name="XXX"

PŘÍKLADY:

  // SOURCE: XML Tag=<Step>, Number="17", Name="ServoPosCount"
  // SOURCE: XML Tag=<Transition>, Number="118", Name="Trans118"
  // SOURCE: XML Tag=<Action>, Qualifier="N", Event="S1"

MAPOVÁNÍ:
  XML ID → SCL řádek
  17 → STEP_Flow2_S17
  118 → Transition condition

================================================================================
DALŠÍ POSTUP
================================================================================

Pro plnou 1:1 konverzi všech flow bloků je třeba:

1. Projít každý XML soubor
2. Extrahovat všechny Step elementy s jejich Actions
3. Extrahovat všechny Transition elementy s jejich Token texty
4. Rekonstruovat graf vazeb
5. Generovat SCL s CASE stavovým strojem
6. Zachovat všechny komentáře pro traceabilitu

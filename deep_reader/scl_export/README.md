# XML → SCL export (offline, for review)

This folder is generated by `deep_reader/xml_to_scl_export.py`.

## Purpose

- Provide **readable SCL representations** of UDTs/DBs/interfaces for audits and refactors.
- This is **not** a behavior-preserving automatic translation of LAD/STL/GRAPH logic.

## Generate

```powershell
python deep_reader/xml_to_scl_export.py --export-root EXPORT --out deep_reader/scl_export
```

## Contents

- `types/` – SCL `TYPE` exports for UDTs (`EXPORT/PLC data types/**/*.xml`)
- `blocks/GlobalDB/` + `blocks/InstanceDB/` – SCL `DATA_BLOCK` interface exports
- `blocks/OB|FC|FB/` – SCL skeletons with extracted interfaces + best-effort StructuredText networks (if present)
- `graph_generated/` – best-effort GRAPH→SCL output via `deep_reader/generate_graph_scl_batch.py` (may include unmapped symbols)
- `manifest.json` – list of generated files and status

## Safety note

These files are generated artifacts for review; do not download them to a running machine without a controlled engineering workflow.
